🔑 ส่งมอบกุญแจรถ

บริษัท (TC) บันทึกข้อมูลเมื่อส่งมอบให้ผู้ใช้รถ

โดยปกติคือผู้ขับขี่หรือผู้จอง — แก้ไขได้หากมีผู้รับแทน

อัปเดตข้อมูลรถ

รถใหม่ต้องใส่ไมล์เริ่มต้นที่นี่ หรือกดแก้ไขจากการ์ดรถภายหลัง

เลือก "ทุกงาน" / การประปา / อื่นๆ หรือกดสร้างกลุ่มใหม่ได้เอง

เพิ่มกลุ่มงานรถ

เก็บไว้อ้างอิงใน Admin (ไม่บังคับตอนจอง)

⚙️ ตั้งค่าระบบ Admin

แจ้ง LINE เมื่อจองรถที่ Admin เปิด แจ้ง LINE + TC (เฉพาะรถงานเฉพาะ) — ต้องกดบันทึกการตั้งค่าหลังใส่ Token

เตือนก่อนส่งรถ (นาที) — ค่าเริ่มต้น 180 (3 ชม.)

ทดสอบส่งเข้ากลุ่มได้ทันที — การจองจริงใช้ค่าที่ บันทึกแล้ว ในชีต Settings

เลือกจากรายชื่อในระบบ — ใช้กับการแจ้งเตือนคิวที่ยังไม่บันทึกไมล์ภายใน 1 เดือน

* หากต้องการเปลี่ยน Username/Password ให้ไปแก้ที่ชีต "Settings" โดยตรงในรูปแบบ Hash
